# Зентор Венопульс №20

Ця директорія містить вихідні дані, контент, бренд-активи та індивідуальні дизайн-токени продукту **Зентор Венопульс №20**.

## Структура

- `brand.md` — позиціонування, аудиторії та комунікаційні повідомлення.
- `product.md` — перевірений опис продукту у зручному для редакторів форматі.
- `product-data.json` — структуровані дані для майбутньої автоматизації.
- `content/` — матеріали за тематичними напрямами.
- `assets/` — логотипи, паковання та зображення.
- `design/brand-tokens.json` — індивідуальні параметри оформлення.

## Правила роботи

1. Додавати лише перевірені дані з указаними джерелами.
2. Не змішувати наукові дані про інгредієнти з дослідженнями готового продукту.
3. Невідомі відомості залишати як `null`, порожній масив або явний `TODO`.
4. Зберігати контент окремо від шаблонів і дизайну.
5. Спільні компоненти та токени брати з `shared/`, не дублюючи їх тут.
6. Дотримуватися загальних правил із кореневого `AGENTS.md`.
