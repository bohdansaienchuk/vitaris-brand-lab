# Графічні ресурси: Беталонг Аміно Плюс

## Директорії

- `logos/` — логотипи продукту.
- `packaging/` — оригінальні та погоджені зображення паковання.
- `images/` — інші зображення, специфічні для продукту.
- `asset-manifest.json` — каталог ресурсів із шляхами відносно директорії `brands/betalong-amino-plus/`.

## Правила

- Не змінювати й не перезаписувати оригінальні файли.
- Зберігати пропорції логотипів і паковання.
- Не вигадувати метадані; невідомі значення майбутніх записів залишати `null`.
- Перед додаванням до Git перевіряти розмір бінарних файлів.
- Для спільних ресурсів використовувати `shared/assets/`, не створюючи зайвих копій.
- Дотримуватися `docs/assets-guidelines.md`.
