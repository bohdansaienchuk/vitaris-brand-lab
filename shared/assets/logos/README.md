# Корпоративні логотипи Vitaris Nutrition Labs

У цій директорії зберігаються спільні корпоративні логотипи. Отримані оригінальні файли потрібно розміщувати в `originals/` без редагування, перейменування або оптимізації.

Похідні варіанти допускаються лише як окремі файли з документованим походженням. Логотипи не можна деформувати, обрізати або змінювати їхні кольори без затверджених бренд-правил.

Загальні правила форматів, прозорості, найменування та Git наведено в `docs/assets-guidelines.md`.
